# HOVER DODGE

> 宇宙海賊団バイデントを追え — ネオン・サイバーパンク調のフラッピーバード系回避ゲーム。

Three.js + WebGL で描画する、タップひとつで遊べる横スクロールのアーケードゲームです。ブラウザだけで動き、PWA としてホーム画面に追加すればオフラインでも遊べます。

**▶ 遊ぶ：<https://junia2009.github.io/hover-dodge/>**（スマホは横向きで。ホーム画面に追加するとアプリのように起動します）

- **4 章のストーリー（完結）**：小さな鳥のパイロット **レイ** と相棒 AI **パラス** の物語。プロローグ・エピローグ・回想は 3D カットシーンで、あとから LOG で見返せる
- **ボス戦 11 体**：第一部 STYX / ACHERON、第二部 ORTHROS / CHARON / 三つ首の CERBERUS、第三部 THANATOS / HYPNOS / THE GATE、最終章 LETHE / EREBUS / NYX
- **やり込み**：パイロットレベル（最大 Lv80）、42 スキルのツリー、装備枠、HULL（耐久）、シナジー、スキン、9 つの隠し要素
- **3D モデル**（glTF）と、プレイに合わせて変化する **手続き合成の BGM**

## 📖 ストーリー

最強の盾の名を冠した美しい星 **アイギス**。宇宙パイロットに憧れる小さな鳥 **レイ**（自分ではクールなつもりだが、どこか抜けている）は、ある夜、宇宙海賊団 **バイデント** の襲来で故郷を焼かれる。瓦礫から掘り出した古い機体と、そこに眠っていた AI **パラス** とともに、レイは飛び立つ——海賊団を壊滅させるまで、何度だって立ち上がる。

### CHAPTER Ⅰ「BIDENT」
- **プロローグ**（初回 START 時）：星空の丘 → 襲撃 → 瓦礫の中の古い機体とパラス → 点火、離陸
- 飛行 **120 秒で STYX**（力押しの第一の穂先）、**240 秒で ACHERON**（アイギス襲撃の立案者）
- ACHERON 撃破で 3D エピローグ（沈む旗艦 → 帰還 → 夜明けの丘 → 日の出と「BIDENT FALLS」）→ スタッフロール → 称号 **AEGIS PILOT** → そのままランを続行

### CHAPTER Ⅱ「CERBERUS」（ACHERON 撃破で解放）
- タイトルに **CHAPTER Ⅰ / Ⅱ** の切り替えが出現。BIDENT FALLS の数週間後、冥王 **ハデス** の影を追う
- 飛行 **90 秒で ORTHROS**（双頭の猟犬）、**180 秒で CHARON**（捕虜を運ぶ渡し守の輸送要塞）、**270 秒で CERBERUS**（ハデス旗艦・3 段階）
- 第二部プロローグ、カロン撃破後の再会と告白（回想シーンつき）、エピローグ（「CERBERUS FALLS」）→ 称号 **SHIELD BEARER**

### CHAPTER Ⅲ「HYPNOS」（CERBERUS 撃破で解放）
- ソルのビーコンを追って、銀河の果ての「門」へ
- 飛行 **90 秒で THANATOS**（死の番人・鎌の斬撃と跳ね返せない黒い弾）、**180 秒で HYPNOS**（眠りの神・眠りの霧と揺れる子守唄の弾）、**270 秒で THE GATE**（双子が守る門。HP 半分で扉が開き、渦から螺旋弾）
- 新要素 **眠気ゲージ（ZZZ）**：霧の中を飛ぶとたまり、満タンで 3 秒間うとうと（羽ばたきが弱く、重く、視界が暗くなる）。**PULSE で霧を払える**
- 第三部プロローグ、ヒュプノス撃破後の「夢」、エピローグ（「SOL RETURNS」）→ 称号 **SON OF THE SUN**、**ソルの機体**（SOL スキン＋SOL 系統スキル）を解放

### CHAPTER Ⅳ「NYX」（THE GATE 撃破で解放・最終章）
- 星がひとつずつ消えていく。夜の女神 **ニュクス** が目を覚ました

- 新要素 **夜**：章のあいだずっと、機体のまわりしか見えない。**PULSE で一瞬広く照らせる**
- 新要素 **忘却**：レテの泡に触れると、装備スキルをひとつ 8 秒間「忘れる」（使えなくなる）。**PULSE で全部思い出す**

各章のエピローグ（とスタッフロール）が終わると、その周回は **CHAPTER CLEAR** としてリザルト画面へ（ランは続かない）。

### ✈ PILOT MODE（最終章クリアで解放）
- パイロット試験に合格したレイが、平和になった銀河を巡る旅。初回は丘での見送りシーン（制服姿のレイと、ソル・ミモザ・ハデス、樹の中のパラス、そして新しい相棒）から
- 相棒は正式に支給された新米 AI **パウロ**（PAULO）。パラスほど賢くないが、好奇心旺盛でレイを「先輩」と慕う後輩タイプ。パラス先輩の話とレイの武勇伝が大好物で、航路のサポートと**記録係**としては優秀（「記録しました！ 先輩の名場面 No.○○！」）。パラスは盾の樹の核になったので、飛行中の無線には出てこない
- **エンドレス**：落ちない限りずっと飛べる。残党（通常の敵）は出るが、**ボスは出ない**
- 全体が明るい空色になり、背景をさまざまな色の惑星（輪のある星も）が流れていく。区間名も旅仕様（アイギスの青空 → ひまわり星雲 → 星の街道 → 銀河の果てへ）
- BGM は専用の明るい曲（C リディアン、軽いスウィング）。無線ではパウロのおしゃべりに、家族や元敵たちが割り込んでくる

### 物語の見せ方
- **3D カットシーン**：タップ / SPACE で進行、SKIP / ESC で飛ばせる。**LOG** から全 13 シーン（Ⅰ 序章・終章 / Ⅱ 序章・告白・終章 / Ⅲ 序章・夢・終章 / Ⅳ 序章・盾・記録・終章 / ✈ 出発）を見返せる
- **無線**：プレイ中、レイとパラス（ボス戦では敵も）の掛け合いが画面下に流れる。前回の死因・時間帯・章・進行状況に応じて変わり、出撃をまたいで進む連作ネタもある
- **航海日誌（LOG）**：記録・フェーズ到達・ボス撃破などで全 24 ページが解放される
- **リザルト**：レイの一言（クールに決めようとして決まらない）
- **区間**：PHASE 1〜4 = アイギス上空 / バイデント前線 / 監視宙域 / バイデント本拠

### ボス戦の基本
- 壁と通常の敵が止まり、旗艦が画面右側に陣取る
- **エネルギーコア** を 3 つ集めると主砲 **AEGIS CANNON** が自動発射（誰でも倒せる軸）
- 大型弾を **PULSE で跳ね返す** と大ダメージ。射撃スキルの弾でも削れる
- 攻撃：扇状弾幕、予告付きレーザー（安全地帯あり）、レーザー掃射、ゲート召喚、追跡機雷、交互射撃、上下からの挟み撃ち、環状弾 など。HP 50% で激化
- **CERBERUS** は HP を 1/3 削るごとに首が 1 本ずつ折れる（炎の首＝3 連扇状弾 → 氷の首＝隙間のある弾の壁 → 闇の首＝反射できない闇の弾。闇の弾は PULSE で消せる）

## 🎮 遊び方

- **タップ / SPACE** — 自機を上昇させる（重力で落ちる）
  - `FORWARD SHOT` 系を装備していればタップで前方弾も発射
- **PULSE / `Z`** — 範囲攻撃。周りの敵を一掃し、ボスの大型弾を跳ね返す
- **`ESC` / `P` / ⏸ ボタン** — 一時停止 / 再開（タブを離れると自動ポーズ）
- **`M`** — 音をまとめて ON / OFF。BGM と SE は個別にも切り替えられる（タイトル下部・一時停止画面）
- **カットシーン** — タップ / SPACE / ENTER で次へ、SKIP / `ESC` で飛ばす
- スコア = 生存秒数（OVERDRIVE 中は 1.5 倍）

ゴールはひたすら長く生き残ること。死んだら `RETRY` ですぐやり直せます。記録・XP・進行はすべて端末に保存されます。

### タイトル画面
- **STORY / ✈ PILOT** — モードの選択（最終章クリア後）。STORY を選ぶと、その下で **CHAPTER Ⅰ〜Ⅳ** を選べる（第二部以降の解放後）。PILOT から STORY に戻ると、最後に選んでいた章に戻る
- **LOADOUT** — 所持スキルの装備・ランクアップ
- **SHOP** — XP でスキルを解放
- **SKIN** — 自機の色
- **LOG** — 航海日誌と、カットシーンの再生
- **SECRETS** — 見つけた隠し要素の ON / OFF と称号（1 つ見つけると出現）

### 縦画面
ゲームは横画面専用です。縦にすると「横向きにしてください」の画面になり、自己ベスト・パイロットレベル・ストーリーの進行（倒したボス）が表示されます。背景では 3D の **レイが羽ばたきながら飛び回り、パラスがあとを追い、ときどき自機が横切ります**。第二部でミモザを救出すると、画面の下でひまわりの世話をしています。第三部をクリアするとソルも加わり、ゆったり滑空しながら宙返りを見せます。キャラクターをタップすると反応します。SHOP / LOADOUT / SKIN / HOW TO PLAY は縦画面からも開けます。

## 📈 フェーズ進行

スコアに応じて4段階に難易度が変化し、**BGM もそれに合わせて重厚化**します。

| Phase | スコア帯 | 敵構成 | BGM |
| :---: | :---: | --- | --- |
| **1** | 0 – 20 sec   | `WALLS` 壁のみ。練習フェーズ            | アンビエントパッドのみ |
| **2** | 20 – 50 sec  | `BULLETS` プラズマ弾型の敵が登場          | + ベース + キック |
| **3** | 50 – 100 sec | `SEEKERS` 追跡型シーカーが混入            | + リードリフ |
| **4** | 100 sec +    | `CHAOS` 全敵 + 最高速度                   | フルミックス |

フェーズ遷移時にはバナーと SE が再生され、BGM もスムーズにクロスフェードします。難易度の数値も境界で急変せず、8 秒かけて次のフェーズへ移行します。

壁の隙間は「前の隙間から人間が余裕をもって届く範囲」にだけ出現します（実際の重力・羽ばたき・速度から毎回計算し、人間の限界の 65% に制限）。運で詰む配置は出ません。

## 🧊 3D モデル

`models/` に glTF（`.glb`）を置いています。起動時に自機・レイ・パラスを読み込み、第一部のボス 2 体はバックグラウンドで、第二部のモデル 5 体は CHAPTER Ⅱ が解放されてから読み込みます（読み込めなかった場合は従来のコード生成モデルで動作）。

| ファイル | 内容 | 向き / 備考 |
| --- | --- | --- |
| `ship.glb` | 自機 | 機首 +X・上面 +Z。`hull` / `wingTop` / `wingBottom` / `cockpit` / `engine` / `flame`（スキンで色替え） |
| `ray.glb` | レイ（原案モデル: RYOHEI TAKAUCHI） | 正面 +Z・足元が原点。`wingL` / `wingR` / `leaf` はピボット付き |
| `pallas.glb` | パラス | 正面 +Z。`orbit`（盾リング）/ `finL` / `finR` / `eye` |
| `styx.glb` / `acheron.glb` | バイデント旗艦 | 船首 -X・上面 +Z。`prongTip_L/R`（発射口）/ `core` / `engine_L/R` |
| `orthros.glb` / `charon.glb` | 第二部のボス | 同上。オルトロスは双頭（`head_L/R`）、カロンは `core` がランタン |
| `cerberus.glb` | ハデス旗艦 | 同上＋三つ首 `head_L/C/R` と `prongTip_L/C/R`（首ごとに破壊して非表示にできる） |
| `thanatos.glb` / `hypnos.glb` | 第三部のボス（双子） | 同上。タナトスは鎌の先と船首、ヒュプノスは 2 本の触角の先が発射口 |
| `gate.glb` | 冥界の門 | 上面 +Z が門の正面。扉 `doorL` / `doorR` を左右に開ける、奥に渦 `vortex*`、双子像の手が発射口 |
| `mimosa.glb` / `sol.glb` | ミモザ（祖母）／ソル（父） | レイと同じ規格（正面 +Z・足元が原点・`wingL/R`）。ミモザは `flower`、ソルは `scarf` / `crest` |
| `lethe.glb` / `erebus.glb` | 最終章のボス | 船首 -X・上面 +Z。レテは半透明のクラゲ船（前に伸びる 2 本の触手が発射口）、エレボスは黒い六角板の壁（上下の端が発射口） |
| `nyx.glb` | 夜の女神 | 同上。星を縫い込んだ夜空のマント `wingL` / `wingR`、三日月の冠 `crown`、ヴェール `veil` |
| `hades.glb` / `nyxbird.glb` / `lethebird.glb` | カットシーン用のハデス／ニュクス／レテ | レイと同じ規格。ハデスは `cape`、ニュクスは `veil`、レテは `bow` |
| `paulo.glb` | パウロ（PILOT MODE の新米 AI） | 正面 +Z・ボールの中心が原点（浮いているドローン）。`armL` / `armR` / `antenna` はピボット付き、`eye` / `rec`（REC ランプ）/ `jet`（スラスター） |

- モデルは Service Worker の専用キャッシュ（`hoverdodge-models-v1`）に長く保存されます。モデルを差し替えたときは `index.html` の `MODEL_REV`（URL に `?v=` を付ける）を上げると、端末のキャッシュを飛ばして新しいモデルが届きます
- 第一部のボス・カットシーン用の小物（ひまわり、ポッド、焚き火など）はコードで生成しています

## 🎁 スコア・ボーナス

**スコア＝生き残った秒数**です（OVERDRIVE 中は 1.5 倍で進む）。スレスレ通過や撃破のボーナスは **XP** として加算され、画面のポップアップも実際に得た XP をそのまま表示します。

| アクション | ボーナス |
| --- | :---: |
| 壁スレスレ通過 `CLOSE`（隙間中央から外側 30 % 以内） | **+3 XP** |
| 極スレスレ通過 `NEAR!`（外側 15 % 以内） | **+8 XP**（OVERDRIVE 中 ×2） |
| 敵を撃破（PULSE / 弾 / 連鎖） | **+5 XP** |
| ノーパルス継続（5秒以上） | `PURIST` 表示 |

## ✨ XP & スキルツリー

ランごとに XP が貯まり、タイトル画面の `SHOP` でスキルを**解放**し、`LOADOUT` で**装備・ランクアップ**します。全 **36 スキル**（ATTACK / DEFENSE / PASSIVE / VITAL の 4 系統）、各ブランチの最深部は **★ULTIMATE**。VITAL 系はパイロットレベルで解放。

### XP 獲得

| ソース | XP |
| --- | :---: |
| 生存（時間経過） | +2 / 秒 |
| 敵撃破（PULSE / 弾 / 連鎖） | +5 |
| 壁スレスレ通過 / 極スレスレ (NEAR!) | +3 / +8 |
| **XP オーブ**（壁の隙間に出現。縁寄りは価値 2 倍） | +5 / +10 |
| PHASE 4 初到達 | +60 |

### 仕組み
- **ランク** — 一部スキルは Lv2〜3 に強化可能（ノードの ●●○ が現在ランク）

## 🎵 インタラクティブミュージック & サウンド

外部音源ファイルを使わず、**WebAudio で全て手続き合成**しています。BGM は固定ループではなく、プレイ内容にリアルタイムで反応します。

### 横の再構成（セクション切替）
タイトルと各フェーズに専用のセクションがあり、テンポ・コード進行・グルーヴが変わります。切替は**必ず次の小節頭**で行われ、着地点にクラッシュ + サブドロップが入ります。ゲーム側がフェーズ到達を予測し、**1 小節前からライザー + スネアロール**を走らせて小節頭に合わせます。

| PHASE 1 | 100 | Am – F – C – G   | パッド / ベース / ハーフタイムキック |
| PHASE 2 | 108 | Am – F – G – Em  | + 4つ打ち / クラップ / 8分ベース |

### 縦のレイヤリング（リアルタイムパラメータ）
- **危険度 (intensity)** — 前方の壁の縁・敵との近さ。テンションレイヤー、ハイハットの16分刻み、ベースのフィルター開放を駆動
- **ヒート (heat)** — NEAR / 撃破の連続で上昇し時間で減衰。アルペジオが入り、最高潮でリードが 1 オクターブ上へ

### 拍に同期するスティンガー
- **NEAR** — 次の16分に量子化されたベル音。**現在のコードの構成音**で、コンボが続くほど音程が上がっていく（極スレスレは 2 音）
- **撃破** — コードスタブ
- **10 秒ごと** — 次の拍にシンバルのアクセント

### ゲーム状態とミックス
- **ポーズ** — 音楽がこもる（ローパス 650Hz）
- **スローモーション** — 時間の遅さに合わせてフィルターが沈む
- **死亡** — 音楽が「電源断」のように 1.3 秒でフィルター閉鎖 + フェードアウト → ゲームオーバーの下降フレーズ → タイトルのアンビエントが戻る
- **新記録** — リザルト表示時に A メジャーのファンファーレ
- **PULSE / SHIELD** — 音楽をサイドチェインで一瞬ダッキング。キックでも常にポンピング

### 効果音
- NEAR はステレオで左から右へ抜ける風切り音、PULSE はサブドロップ + ノイズスイープ + 下降アルペジオ
- UI（ショップ購入 / 装備 / スキン / メニュー開閉）にも専用サウンド
- **しゃべる声** — セリフの文字送りに合わせて、話者ごとに違う短い音が鳴る（レイはさえずり、パラスは電子音、ハデスは低いうなり など）。プレイ中のタップ音はなし
- BGM と SE は別々のバス（`AU.bgmGain` / `AU.sfxBus`）で、個別に ON / OFF できる

### ミックス構成
`各レイヤー → キックダッキング → PULSEダッキング → musicBus → 可変ローパス → master → コンプレッサー`。リバーブ（合成インパルス）と付点8分ディレイ（テンポ同期）をセンド。最初のタップ / キー入力でタイトル曲が始まり、タブを離れると AudioContext ごと一時停止します。

## 🛠 技術スタック

- **Three.js** (r160, CDN) — シーン / ライティング / ポストプロセス（UnrealBloomPass + 自作レンズシェーダー）/ **GLTFLoader**
- **Vanilla JS (ES Modules)** — ゲームロジック、入力、状態管理。モデルはトップレベル `await` で読み込み（失敗時はコード生成モデル）
- **カットシーン** — プロローグ / 第一部エピローグは専用実装、第二部の 3 シーンは汎用エンジン `Cine`（台詞・タイプライター・SKIP・ベール遷移・カメラ補間）。回想は `backdrop-filter` のセピア、ソルのホログラムは `ShaderMaterial`（縁の発光 + 走査線）
- **縦画面の 3D** — 別の小さな WebGLRenderer（`Rot3D`）。縦画面のときだけ動き、その間は裏の横画面の描画を止める
- **DOM + CSS** — HUD / 各画面（`#ui` レイヤー。`--px` = 仮想画面 1px でスケール）
- **Canvas 2D** — ワールド座標に追従するスコアポップアップ
- **Web Audio API** — SE・声・インタラクティブ BGM をすべて手続き合成（lookahead スケジューラ）
- **Service Worker** — オフライン / PWA。ページ本体はネット優先、3D モデルは専用キャッシュ、その他は stale-while-revalidate。新しいバージョンが出るとタイトルに「NEW VERSION — タップで更新」
- **アクセス解析（GoatCounter）** — Cookie なし・個人を特定する情報なし。`index.html` の `GC_CODE` にサイトコードを入れると有効になる（空なら何も送らない。localhost やテスト環境では送らない）。管理画面で読みやすいよう、記録名は日本語＋絵文字：
  - `🎮 ゲームを開いた` — ページ表示（`/` と `/index.html` をまとめる）
  - `🚀 出撃：第一章`〜`最終章` / `パイロットモード`
  - `⭐ 初撃破：STYX（第一章）` / `⚔ 撃破：…` — ボス撃破（はじめてか、2 回目以降か）
  - `🏆 クリア：第一章` — エンディング（スタッフロール）まで見た
  - `💥 撃墜：最終章 PHASE 3` — どこでやられたか
- **localStorage**:
  - `hd_hi` — 自己ベスト（秒）
  - `hd_xp` / `hd_xp_life` — 所持 XP / 累計獲得 XP（パイロットレベルの元）
  - `hd_owned` / `hd_equip` / `hd_ranks` / `hd_slots` — 所持スキル / 装備 / ランク / 装備枠
  - `hd_skin` — 機体スキン
  - `hd_bgm` / `hd_se` / `hd_mute` — 音の設定
  - `hd_boss` / `hd_boss2` / `hd_boss3` / `hd_boss4` / `hd_boss_met` — 撃破数（第一部〜最終章）/ ボス遭遇回数
  - `hd_chapter` / `hd_prologue` / `hd_prologue2` / `hd_prologue3` — 選択中の章 / プロローグ視聴済み
  - `hd_runs` / `hd_maxphase` / `hd_logs_read` / `hd_comm` / `hd_lastrun` / `hd_short` / `hd_gag` — 出撃回数・最高到達フェーズ・既読日誌・会話履歴・前回の結果・連続短時間ミス・連作ネタの進行
  - `hd_secrets` / `hd_sec_opts` — 隠し要素

ゲーム本体は `index.html` 1 ファイル（CSS / JS 全部入り）。依存は CDN の Three.js と Google Fonts（Orbitron / Rajdhani）のみで、どちらも Service Worker がキャッシュします。

## ⚙️ 開発・実行

ローカルで動かす場合は静的サーバを立てるだけ：

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

ブラウザで `http://localhost:8080` を開く。

> ⚠️ Service Worker は `file://` プロトコルでは動きません。動作確認は必ず HTTP 経由で。

### ファイル構成

```
hover-dodge/
├── index.html       ← ゲーム本体（HTML + CSS + JS 全部入り）
├── sw.js            ← Service Worker（オフラインキャッシュ）
├── manifest.json    ← PWA マニフェスト
├── icon.svg         ← ベクターアイコン（manifest の primary）
├── icon-180.png     ← iOS apple-touch-icon (180x180)
├── icon-192.png     ← Android maskable (192x192)
├── icon-512.png     ← Android maskable (512x512)
├── make-icons.html  ← アイコン PNG 再生成用ページ
├── models/          ← 3D モデル（glTF .glb）
├── docs/
│   └── LORE.md      ← 世界観・キャラクター・ストーリーの設定資料
└── README.md
```

### バージョン管理

バージョン番号は `index.html` の **`const VERSION = 'X.Y.Z'` の 1 か所だけ**です。タイトル・縦画面の表示も、Service Worker の登録（`sw.js?v=X.Y.Z` → キャッシュ名 `hoverdodge-vX.Y.Z`）もここから決まります。リリースのときは `VERSION` と README のバッジ・履歴を更新します。

アイコンを変更した場合は `make-icons.html` をブラウザで開いて PNG を再生成・差し替えてください（iOS の `apple-touch-icon` は SVG を受け付けないため PNG 必須）。

## 🎨 ビジュアル特徴

- **解像度追従レンダリング** — 800×450 の仮想画面を表示サイズ × devicePixelRatio で描画（最大 2x）。拡大してもボケない
- **レンズ FX** — 自作シェーダーパスで色収差（被弾・NEAR・PULSE で瞬間的に強まる）/ ビネット / スキャンライン / フィルムグレイン / 画面フラッシュ
- **スローモーション** — 死亡・SHIELD・PHOENIX 発動時に時間がスローになり、徐々に通常速度へ戻る
- **ネオン・グロー** — UnrealBloomPass による HDR 発光
- **3D モデル** — 自機・キャラクター・旗艦は glTF。自機はスキンで塗り替え、旗艦は被弾で発光、CERBERUS は首ごとに壊れる
- **壁** — マゼンタ系ネオン + パルスエッジ
- **敵 2 種** — `BULLET`（リング付きプラズマ球）/ `SEEKER`（旋回速度キャップ付き追跡矢印型）
- **PULSE** — 二重拡張リング + バーストスパーク
- **SHIELD ブレイク** — 緑のリングで周囲の敵を巻き込む防衛発火
- **前方弾** — シアンの小さな弾、衝突で敵をスパーク化
- **背景** — シンセウェイヴ風の奥行きグリッド（床・天井、フォグで地平線に溶ける）+ 加算合成ネビュラ + スターフィールド + スピードライン
- **エンジントレイル** — スキン色の加算合成リボンが航跡を描く
- **シールド** — SHIELD 装備中は機体の周りにバブルが表示
- **UI** — Orbitron / Rajdhani による DOM ベースの HUD・タイトル・リザルト・ポーズ画面（ゲーム画面と一緒にスケール）
- **3D カットシーン** — 丘・星空・夜明け・焼けた惑星などをシーンごとに組み、カメラワークと日の出の空のグラデーションで演出
- **縦画面待機** — ブランドロゴ + タクティカルスコープ + 自己ベスト + パイロットレベル + ストーリー進行 + 3D のキャラクター

## 📱 対応環境

- iOS Safari 15.4+ / Chrome / Edge / Firefox
- 横画面（landscape）専用 — 縦持ち時はオーバーレイで誘導
- Safe Area（ノッチ・ホームインジケーター）対応
- 60 / 120 / 144 Hz 端末で同一の難易度（dt ベースのタイムステップ）
