# HOVER DODGE 設定資料（LORE）

今後のアップデート（会話・日誌・ボス・ストーリー）を作るときの基準。
**【確定】** はゲーム内に既に出ている／決定済みの設定、**【案】** は今後の候補（変更可）。

## 世界

### 惑星アイギス【確定】
- 最強の盾の名を冠した、美しい星。青い海、背の高い木々、降ってきそうな星空。
- 宇宙海賊団バイデントの襲撃で、一夜にして焼き尽くされた。

### 盾の樹【確定】
- アイギスのシンボルだった大樹。星の守り神のように扱われていた。
- 襲撃で焼失。**生き残った最後の緑は、レイの頭の葉っぱだけ**。

### アイギス・シールド【確定】
- 惑星を包む防衛システム。複数の戦術 AI が管理していた（そのひとつがパラス）。
- 襲撃の夜、**内側から**破られた（後述のアケロンの仕込み）。

## キャラクター

### レイ（RAY）— 主人公【確定】
- 丸いフォルムの鳥。上半身は左が青・右が紺、下半身はそれが反転した2色。黄色いくちばし、頭に緑の葉っぱ。
- 自分ではクールだと思っているが、どこか抜けている。
- 宇宙パイロットになると決めている。丘の上で星を見るのが好き。好物はひまわりの種。
- 口ぐせ・信条：「何度だって立ち上がる」。
- 名前の意味：レイ＝光線。父ソル（太陽）の光。

#### 生い立ち【確定】
- **父はアイギス防衛隊のエースパイロット「ソル」**。レイが小さい頃から任務で家を空けがちで、レイは主に祖母ミモザに育てられた。
- レイのクールぶったポーズや決め台詞は、全部「伝説のパイロット・ソル」の真似（だから微妙に似ていない）。
  ※ レイは父のことを「憧れのエース」としては知っているが、**機体やパラスと父のつながりは知らない**。
- 頭の葉っぱ：ヒナの頃、盾の樹の種が頭に落ちて根付いたもの。祖母は「樹に選ばれたんだね」と笑っていた。
- 防衛隊パイロット学校の入学試験に**3回落ちている**（実技は満点、筆記で不合格）。

#### 襲撃の夜【確定】
- いつもの丘で星を見ていたため生き延びた。
- 瓦礫の中で、古い機体と眠っていたパラスを見つける。

#### 祖母ミモザ（MIMOSA）【確定】
- ソルの母。任務で家を空けがちなソルに代わって、レイを育てた。
- 丘のふもとで、ひまわりを育てていた。**レイの好物のひまわりの種は、ミモザの畑の味**。
- 星座の名前をレイに教えたのもミモザ。レイが丘で星を見るのは、その習慣から。
- 【確定】襲撃の夜、バイデントに捕らえられていた。第二部で**カロンの輸送要塞から救出され、レイと再会**する。
- 口調：おっとりした年寄り言葉。「〜だねえ」「〜おいで」。レイを今でも「ヒナ」扱いする。

### パラス（PALLAS）— 相棒の AI【確定】
- 古い機体に眠っていた戦術 AI。元はアイギス・シールドを管理する AI のひとつ。
- 冷静で口が悪く、たまに優しい。レイの衝突回数を正確に数えている。
- 夢：「あなたが無事に帰ること」。
- 外見（3D モデル）：白い球体のドローン。フクロウの耳のようなヒレ、六角形のバイザーと単眼、周りを回る六角形の盾。
- 名前の由来：女神パラス・アテナ（盾アイギスの持ち主、象徴はフクロウ）。

#### 抱えている罪悪感【確定】
- 襲撃の**約1年前**、パラスはシールドのデータ中に**不審な書き換え（裏口）**を見つけ、評議会に警告した。
- しかし証拠が不十分とされ、逆に「誤作動を起こした AI」として**シールドから外され、凍結処分**に。
- それを惜しんだソルが、退役した自分の愛機（＝今の機体）にパラスを保存した。
- 襲撃の夜、その裏口が開き、シールドは内側から崩れた。
- パラスは「**自分がもっと強く訴えていれば**」「**眠っている間に、星が焼けた**」と思い続けている。
  口の悪さや冷たさは、その気持ちを隠すため。レイの無事にこだわる理由もここにある。

#### 前の操縦士【確定】
- **前の操縦士は、レイの父ソル**。
- ソルは機体にパラスを残すとき、最後の命令を与えた：「**次にこいつで飛ぶ奴を、守ってくれ**」。
- 初対面の「ずいぶん小さいですね」は、ソルと比べたひと言。パラスは生体データの一致から、**レイがソルの子だと最初から気づいている**が、まだ話していない。

#### 小さな癖【確定】
- 数を数えるのが好き。
- 「機械」と呼ばれると少し不機嫌になる。
- レイの良い飛行を、こっそり別フォルダに保存している（「記録しました」の本当の意味）。

### ソル（SOL）— レイの父【確定】
- アイギス防衛隊のエースパイロット。豪快で、少し抜けているところはレイにそっくり。
- パラスの警告を信じた、ほぼ唯一の人物。
- **襲撃の約半年前、バイデントの偵察任務で消息を絶った**。公式記録は「作戦中行方不明（MIA）」。
- 【確定】**生死は第二部でも明かさない**（第三部へ引っぱる）。第二部では「手がかり」だけが出る（下記・第二部 第5幕）。
- 【確定：第三部】**生きている。眠りの神ヒュプノスに「永遠の眠り」に閉じ込められている**。
  かつてハデスを一度撃退した帰りに「門」の向こうへ追い込まれ、捕らわれた。ビーコンは、眠りの中でも機体の識別コードを送り続けていたもの。
- 【確定：第三部】救出後は**遊べる機体**になる（第三部クリアで解放：オレンジのソル専用スキン＋専用スキル）。

## 宇宙海賊団バイデント

ギリシャ神話の冥王ハデスの武器「二又の槍（バイデント）」が名前の由来。旗印は二本の穂先の槍。

### ステュクス（STYX）— 第一の穂先【確定】
- でかい図体、でかい声。何度負けても懲りない。力押しの戦い方。
- 旗艦：重装甲の戦艦。巨大な二又の衝角、赤く光るコア。
- 最期の言葉は「アケロンに……笑われちまう……」。アケロンを相棒としても、張り合う相手としても意識している。

### アケロン（ACHERON）— 第二の穂先【確定】
- **アイギス襲撃の立案者**。冷酷で、美しいものを好む。
- 旗艦：紫の細身の刃。三日月の翼、二重の光輪、背に結晶の尖塔。
- 【確定】襲撃の1年以上前、交易船のデータに偽装して**アイギス・シールドに裏口を仕込んだ**張本人。パラスの罪悪感の直接の原因。
- 「美しい星だったね、アイギスは。燃える様も含めて。」

### ハデス（HADES）— 槍を握る者【確定：第二部のラスボス】
- バイデントの頭領、海賊王。STYX と ACHERON は「穂先」にすぎず、槍を握るのはハデス。
- 第一部のエンディング「BIDENT FALLS」は、**穂先が折れただけ**。ハデス本人は姿を見せていない。
- 目的：銀河じゅうの「伝説の盾」を集めて、何者にも傷つけられない存在になること。
  アイギスを襲った本当の狙いは、アイギス・シールドの核と、**盾の樹**。
  → 盾の樹の最後のかけら（レイの葉っぱ）が、今度は狙われる。
- 旗艦：**ケルベロス**（冥界の三つ首の番犬）。三つの砲塔＝三つの首を順に折っていく、3段階のボス戦。
- ソルとの因縁：かつてソルに一度だけ撃退されたことがある。

## ストーリー構成

### 第一部（現在のゲーム）【確定】
プロローグ（アイギス焼失 → パラス起動 → 離陸）→ STYX 撃破 → ACHERON 撃破 → エピローグ（BIDENT FALLS、称号 AEGIS PILOT）

#### エピローグ【確定】（3D カットシーン、ACHERON 撃破後に LOG から再生可）
1. **沈むアケロン**：アケロン最期の言葉「槍は……まだ、折れては……いない……」（ハデスへの伏線）。残党は散り散りに逃げる。
2. **帰還**：焼けたアイギスへ。「……帰ろう。アイギスに。」
3. **夜明けの丘**：プロローグと同じ丘に着陸。パラス「……長いあいだ、眠っていました。起こしてくれて、ありがとうございます。」（凍結されていたことのほのめかし）
4. **日の出**：最初の光がレイの葉っぱ（アイギス最後の緑）を照らす →「BIDENT FALLS — アイギスの空に、朝が来た。」

## 第二部「CERBERUS ─ 冥界の番犬」【確定：方針】

**テーマ**：「守られる側」から「守る側」へ。父の背中の真似をやめて、自分の飛び方を見つける。
**モチーフ**：冥界の川（ステュクス・アケロン）を越えて、さらに奥へ。渡し守カロン、門番ケルベロス、冥王ハデス。

### 遊び方【確定】
- 第一部クリア（ACHERON 撃破）後、タイトルに **CHAPTER 2** が解放され、第二部だけを最初から遊べる。
- 第二部専用のプロローグ／エピローグ（3D カットシーン）、LOG から再生可。
- ボスは 3 体：オルトロス → カロン → ケルベロス（3段階）。
  出現タイミングは 1:30 / 3:00 / 4:30（実装済み）。

### 敵【確定】
#### オルトロス（ORTHROS）— 猟犬
- 残党をまとめ直した、ハデス直属の追跡者。ケルベロスの兄弟（双頭の犬）が由来。
- 小型で速い双胴艦。しつこく追い回し、左右の首（砲塔）で挟み撃ちにしてくる。
- 口調：短く、獣っぽい。ハデスを「主（あるじ）」と呼ぶ。「その芽を寄こせ。主がお望みだ」「……匂うぞ。盾の樹の匂いだ」
- 【案】撃破時「主よ……芽は、本物です……」

#### カロン（CHARON）— 渡し守
- 冥界の川の渡し守が由来。アイギスの生存者を捕虜として運ぶ**巨大輸送要塞**。
- 本人は戦いを好まない商人気質。運賃（取引）にうるさい。
- 口調：慇懃で計算高い。「渡し賃は、いただきますよ」「積み荷に傷がつくと困るのですがねえ」
- 撃破すると捕虜が解放され、**ミモザと再会**。

#### ハデス（HADES）— 冥王
- 旗艦**ケルベロス**：三つの首（砲塔）を一つずつ折っていく3段階戦。首ごとに攻撃が変わる。
  【案】左の首＝炎（範囲）、右の首＝氷（減速）、中央の首＝闇（反射を打ち消す）
- 狙い：銀河じゅうの「伝説の盾」を集め、何者にも傷つけられない存在になること。
  アイギスを襲った本当の目的は、アイギス・シールドの核と**盾の樹**。
- **盾の樹の芽（レイの葉っぱ）は、盾の樹そのものを再生できる唯一の種**。だから狙われる。
- 口調：低く短い。感情をほとんど見せない。一人称「我」。「芽を渡せ。それは盾だ。お前には過ぎた盾だ」
- かつてソルに一度だけ撃退されたことがある（これがハデスがソルを知っている理由）。

### あらすじ（5幕）【確定】
1. **残党の通信**（第二部プロローグ）
   BIDENT FALLS から数週間後、丘で野営するレイとパラス。傍受した通信「穂先は折れた。だが槍は、主の手にある」。
   その瞬間、**レイの葉っぱが初めて光る**。パラス「……今の反応、記録しました」
2. **猟犬オルトロス**
   オルトロスが葉っぱを狙って追ってくる。「なぜ俺の葉っぱなんだ？」という謎が生まれる。
3. **渡し守カロン**
   輸送要塞を撃破し、捕虜を解放。その中に**祖母ミモザ**。
   ミモザ「レイ……大きくなったねえ」。ひまわりの種の袋を渡される（レイの好物の原点）。
4. **パラスの告白**（カロン撃破後のカットシーン）
   ミモザが機体を見て「これ、ソルの……」と口にし、パラスが隠しきれなくなる。
   シールドの裏口、凍結処分、そして「前の操縦士はソル——あなたの父です」。
   レイ「……なんで黙ってた」／パラス「……怖かったんです。あなたまで、いなくなる気がして」
   レイ「……バカだな。何度だって立ち上がるって、言っただろ」
   告白の途中に回想「襲撃の、一年前」：ソルが凍結予定のパラスを退役した愛機に隠し、最後の命令を与える場面（ソルが本来の姿で登場する唯一の場面）。
5. **ケルベロス**（第二部エピローグ）
   ハデスとの3段階戦。撃破後、焼けた丘に葉っぱを植え直す → **盾の樹の芽が出る**。
   パラス「おかえりなさい、レイ」
   **ソルの手がかり（生死は伏せる）**：沈むケルベロスから、ソルの個人コードで発信された古いビーコン信号を受信する。
   発信元は銀河の果て、「門」の向こう。ハデス最期の言葉「……あの男は、まだ門の向こうだ」。
   → 第三部へ。

## 第三部「HYPNOS ─ 眠りの門」【確定：方針】

**テーマ**：父を取り戻す。かつてソルが凍結されたパラスを救ったように、今度はレイとパラスが眠らされたソルを救う（第二部の告白と対になる構図）。
**モチーフ**：冥界の門のそばに住む双子の神——死のタナトスと眠りのヒュプノス。

### 遊び方【案】
- 第二部クリア（CERBERUS 撃破）で **CHAPTER Ⅲ** を解放。第一部・第二部と同じく、章を選んで最初から遊ぶ。
- **新要素：眠気ゲージ**
  - ヒュプノスの「眠りの霧」の中を飛ぶとたまっていく。
  - 満タンになると数秒間、動きがスローになり、視界が狭くなる。
  - PULSE で霧を払える（PULSE の新しい使い道）。
- ボスは 3 戦の予定：タナトス → ヒュプノス → 門（双子が同時に守る最終戦）。

### 敵【案】
#### タナトス（THANATOS）— 死
- 門の番人。双子の兄。冷たく容赦がなく、無口。
- 攻撃：黒い鎌のような斬撃（画面を横切る斬線）、触れると大ダメージの黒い弾。
- 口調：一人称なし／必要なら「私」。極端に短い。「通さぬ」「終わりだ」

#### ヒュプノス（HYPNOS）— 眠り
- 双子の弟。穏やかで、相手を眠らせる。ソルを眠らせ続けている張本人。
- 攻撃：眠りの霧（眠気ゲージを上げる）、ゆっくり漂う子守唄のような弾幕。
- 悪意よりも「眠っていれば痛くない」という歪んだ優しさで動く。
- 口調：「ぼく」。ゆっくり、やさしく。「おやすみ」「目を閉じて。もう戦わなくていい」

#### 門（THE GATE）— 最終戦
- 双子が守る巨大な門。開閉のリズムに合わせて攻撃が変わる。
- 双子が同時に出てくる（片方を倒すと、もう片方が激化する）。

### あらすじ（案）
1. **ビーコンを追って**：盾の樹の芽が育つ丘から出発。ミモザ「ソルを、連れて帰っておいで」。
2. **タナトス**：門の番人との戦い。「死者は通さぬ」——だが、ソルは死者ではなかった。
3. **ヒュプノス**：眠りの霧。パラスがヒュプノスの霧に一瞬のまれ、凍結されていたときの夢を見る（パラスの弱さを描く）。
4. **夢の中のソル**（カットシーン）：眠るソルの夢にレイが入る。夢の中は、まだ緑だったアイギスの丘。若い頃のソルが、レイを知らないまま話しかけてくる。レイは自分が息子だと名乗れない……。
5. **門**：双子との最終戦。ヒュプノスを倒すと眠りが解ける。
6. **エピローグ**：ソルが目を覚ます。「……でかくなったな」（ミモザと同じセリフで、親子三代がつながる）。パラス「おかえりなさい、ソル」。三人と一体で、アイギスへ帰る。
   → 最後に、門の奥のさらに深い闇から何かが目を覚ます気配（第四部へ）。

### 第三部で解く謎／残す謎
| 解く | 残す（第四部へ） |
| --- | --- |
| ソルは生きている（眠らされていた） | ハデスが集めた「伝説の盾」の行方 |
| 「門」の向こうに何があったのか | 門の奥で目覚めたもの |
| ハデスとソルの因縁（ソルが撃退した帰りに捕らわれた） | 盾の樹の本当の力 |

### ソル（救出後）【確定：方針】
- 第三部クリアで**ソルの機体**が解放（オレンジ×深紅の専用スキン＋専用スキル）。
- 専用スキル案：**SUNBURST**（PULSE が太陽のような光の輪になり、範囲が広い）／**ACE'S INSTINCT**（NEAR の判定が広くなり、NEAR のたびにわずかに回復）。

## 第四部（最終章）【案】
- **筋**：ハデスが銀河じゅうから奪っていた「伝説の盾」を、それぞれの星に返していく旅。行く先々でその星のパイロットが仲間になる。
- **ラスボス候補**
  - **タルタロス**：冥界のさらに下の奈落。ハデスすら恐れていた存在。
  - **ニュクス**：夜の女神。タナトスとヒュプノスの母。
- **結末**：レイが植えた盾の樹が育ち、取り戻した盾とつながって、銀河を守る大きな盾になる。
